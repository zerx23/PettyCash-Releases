# Neptune Lines PettyCash

Instaladores y actualizaciones oficiales para Windows de Neptune Lines PettyCash.

Descarga el instalador `.exe` desde [la versión más reciente](https://github.com/zerx23/PettyCash-Releases/releases/latest). La instalación incorpora el certificado HTTPS público necesario para acceder a la API de la intranet, para el usuario de Windows que instala la aplicación.

El uso de la aplicación requiere acceso a la intranet de Neptune Lines y una cuenta autorizada. Los datos financieros se almacenan en el servidor interno.

Desde la versión 0.1.6, la aplicación comprueba si existen actualizaciones y permite instalarlas después de que el usuario confirme. Las actualizaciones están firmadas.

Este repositorio contiene únicamente los archivos de distribución. El código fuente se mantiene en un repositorio privado. Para soporte, contacta con TI de Neptune Lines.
